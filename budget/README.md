# LexBudget — ניהול תקציב עסקה

מערכת **נפרדת לחלוטין** מה-CRM: מסד נתונים משלה (`lexBudgetDB`), Service Worker משלה (scope `/budget/`),
ומניפסט PWA משלה. אין תלות הדדית בקוד או בנתונים — רק שפה עיצובית משותפת (Obsidian Gold).

**כתובת:** `<אתר>/budget/` — למשל `https://lironcon.com/crm/budget/`
(ה-Worker הקיים כבר ממפה `/crm/*` → `/Law-Order/*`, אין צורך בשינוי).

---

## המתודולוגיה (נגזרת מגיליון התקציב המקורי)

| שלב | חישוב |
|-----|-------|
| שעות תקציב לשורה | `ROUNDUP(שעות מוערכות × (1 + מקדם חריגה))` |
| עלות שורה | `שעות תקציב × תעריף הדרגה` |
| תקציב צוות | סכום השורות |
| תקציב העסקה | סכום הצוותים |
| תעריף בלנדד | `תקציב העסקה ÷ שעות תקציב שאינן ג'וניור` — כל התקציב (כולל עלות הג'וניורים) מגולגל על השעות ה"נמכרות" |
| תעריף ממוצע כולל | `תקציב ÷ כל שעות התקציב` |

כל צוות מקבל **אותה מתודולוגיה**: שורה לכל דרגה בתעריפון, מקדם חריגה (ברמת העסקה או דריסה לצוות),
ותעריף מהתעריפון (עם אפשרות דריסה לשורה בודדת).

## מה נוסף מעבר לגיליון

- **טאב לכל עסקה** בראש המסך, עם נקודת מצב וניצול; גרירה לשינוי סדר.
- **ביצוע מול תקציב בזמן אמת** — לכל שורה, צוות ועסקה: יתרה, ניצול, רמזור (תקין / לתשומת לב / סיכון / חריגה).
- **העלאת חשבונות** — XLSX או CSV עם זיהוי אוטומטי של העמודות ואישור מיפוי, זיהוי כפילויות,
  צירוף קובץ החשבון עצמו (PDF/תמונה) שנשמר מקומית ועובד אופליין.
- **ייבוא תקציב מאקסל** — זיהוי מבנה הגיליון (צוותים, דרגות, תעריפים, מקדם חריגה) ויצירת הצוותים.
- **תחזית לסיום (EAC)** לפי התקדמות מדווחת או לפי קצב לוח הזמנים, עם הסטייה הצפויה מהתקציב.
- **מודלי שכר טרחה** (שעתי / תקרה / פיקס / ריטיינר) עם רווח גולמי ושיעור רווח מול העלות בפועל.
- **תקציב בסיס (Baseline)** — קיבוע תקציב מאושר וזיהוי זחילת היקף.
- **תעריפונים מרובים**, דרגות ניתנות להוספה, סימון דרגת ג'וניור לחישוב הבלנדד.
- **סימון צוותים** לחישוב מצרפי (תקציב/ביצוע/יתרה/ניצול/בלנדד וחלק מהעסקה) של תת-קבוצת צוותים.
- **שיוך עורכי דין לצוותים** בייבוא פירוט שעות — זיהוי השמות בקובץ, שיוך ידני, וזיכרון שנשמר לעסקאות הבאות.
- **תעריף אפקטיבי בפועל** מול הבלנדד המתוכנן.
- גרפים: ניצול, תקציב מול ביצוע לפי צוות ולפי דרגה, שריפה מצטברת, הרכב התקציב.
- ייצוא CSV (עסקה / ביצוע / סקירת תיק) וגיבוי JSON מלא.
- שכפול עסקה כתבנית, שכפול צוות, מחיקת צוות בלי לאבד רישומי ביצוע.

## מבנה הקוד

| קובץ | תפקיד |
|------|--------|
| `js/model.js` | דומיין טהור: קבועים, נרמול, מנוע החישוב (`computeDeal`), התראות, תחזית |
| `js/db.js` | IndexedDB (`lexBudgetDB`): `deals`, `teams`, `entries`, `files`, `rateCards`, `settings` |
| `js/store.js` | CRUD + מטמון בזיכרון + `setMutationListener` |
| `js/xlsx.js` | קורא XLSX/CSV ללא ספריות (ZIP ידני + `DecompressionStream`) |
| `js/importer.js` | זיהוי עמודות, המרת שורות לרישומים, זיהוי מבנה גיליון תקציב |
| `js/ui.js` | רינדור DOM (קלט משתמש כ-`textContent` בלבד) |
| `js/charts.js` | גרפי SVG |
| `js/app.js` | state יחיד, `render()`, event delegation, מודאלים, ייבוא/ייצוא, רישום SW |

## פיתוח

```bash
python3 -m http.server 8765     # ואז http://localhost:8765/budget/
```
בקונסול: `window.lexBudget.seedDemo()` — טוען עסקת דמו עם 5 צוותים ורישומי ביצוע.

**חשוב:** בכל שינוי ב-`index.html` / `css/*` / `js/*` — להעלות את `CACHE` ב-`budget/sw.js`
(`lexbudget-vN` → `lexbudget-v(N+1)`). גרסה נוכחית: **v3**.
