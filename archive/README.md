## מה קיים בהן ועדיין חסר ב-`v2/`

`v2/` (Phase 2, 30.06.2026) פורט ממודול החיוב, ואחריו נוספו בו ייבוא PDF/Excel/CSV, יצירת לקוח
ותיק מחשבונית, השלמה מחשבונית ועוד. מה שלא עבר:

1. **חשבונית זיכוי — סכום שלילי** (Lawfee-2.0, 14.05). ב-`v2/js/billing-app.js` שדה הסכום הוא `min: '0'`,
   ובמסך הסיווג של הייבוא שורה עם `amount <= 0` מדולגת. המקור: `Lawfee-2.0/invoices.js` (הצגה באדום
   ואימות "אפשר שלילי לזיכוי").
2. **ביטול מחיקה (undo)** ללקוח, תיק, חשבונית ותשלום (LawFee, 29.05): מחיקה שומרת snapshot מלא ומציגה
   טוסט עם "בטל" שמחזיר את הרשומות עם אותם מזהים (`UI.toastUndo`, `restore` ב-`LawFee/db.js`).
   ב-`v2/` מחיקה היא סופית.
3. **ייבוא קובץ האקסל השנתי הישן** (שתיהן, `import.js` → `parseWorkbook`): גיליון שנתי של חשבוניות לפי
   חודש, ותשלומים שנקראים מטקסט כמו "דצמבר: 5,257" (`_parsePaymentsFromText`). ב-`v2/` ייבוא האקסל קורא
   שורות חשבונית בלבד. נתונים שכבר יובאו לאחת המערכות עוברים ל-`v2/` דרך ייבוא הגיבוי (JSON),
   ולכן זה רלוונטי רק לגיליון ישן שעוד לא נקלט.
4. **בדיקות תקינות לפני כתיבה** (LawFee, `db.js`): אימות שדות חובה וטווחים בשכבת ה-DB עצמה, לא רק בטופס.
